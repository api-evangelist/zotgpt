# ZotGPT (UC Irvine)

> UC Irvine's institutionally-operated generative AI platform, built and run in-house by the UCI Office of Information Technology AI Team. Multi-cloud (AWS us-west-2 for every application plane, Azure West US 2 for API management), multi-model (OpenAI, Anthropic via AWS Bedrock, Google, Azure, and open-source options), and behind campus SSO end to end. Free to the whole UCI community; developer access is metered in dollar-denominated credits rather than request rates.

Generated by the API Evangelist enrichment pipeline on 2026-07-28 from UC Irvine's public documentation. UC Irvine publishes no llms.txt of its own (probed: 404).

## APIs

- [ZotGPT Gateway](https://zotgpt.uci.edu/services/gateway/): Unified AI API gateway on the Portkey specification. One endpoint, many models, virtual API keys with per-key spend limits. Base URL https://api.portkey.ai/v1 (OpenAI-compatible) or https://api.portkey.ai (Anthropic-style). Provider routing via the x-portkey-provider header carrying a campus alias such as @zotgpt-api-bedrock or @openai-prod.
- [ZotGPT API (Deprecated)](https://zotgpt.uci.edu/services/api/): First-generation OpenAI-compatible chat completions endpoint fronted by Azure API Management at https://api.zotgpt.uci.edu/v1/chat/completions, serving gpt-4o with $200 in starter credits. In phased retirement.

## Products

- [Chat](https://zotgpt.uci.edu/services/chat/): Free general-purpose AI chat for all UCI students, faculty, and staff. File upload, LaTeX, large context, multi-media via Gemini 2.5. History stored in AWS.
- [ClassChat](https://zotgpt.uci.edu/services/classchat/): Course-scoped AI for instructors and students. Up to 1,200 pages of course material per module, instructor-authored prompts, engagement tracking. Runs in its own isolated environment with its own policies.
- [Creator](https://zotgpt.uci.edu/services/creator/): No-code custom assistant builder with document knowledge bases, three access tiers (invite-only, UCI internal, public), and an Agents feature for linking assistants. Over 1,000 bots built.
- [Prompt Library](https://zotgpt.uci.edu/prompts/): 44 curated prompts across ~30 tags for teaching, learning, and research.
- [Academy](https://zotgpt.uci.edu/services/academy/): Self-paced 30-minute AI literacy courses for faculty, staff, and students.
- [Marketplace](https://zotgpt.uci.edu/services/marketplace/): Hub for discovering and sharing community-created AI tools.
